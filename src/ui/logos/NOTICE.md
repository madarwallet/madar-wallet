Logos in this folder come from @web3icons/core 4.0.58 (MIT License, https://github.com/0xa3k5/web3icons),
"background" variants, copied verbatim. They are bundled with the extension; nothing is loaded from the network.
The marks themselves remain trademarks of their respective projects.
tok-ARB.svg is a copy of the arbitrum-one network mark (the package's ARB token file was a different project's logo).
net-solana.svg / tok-SOL.svg: same bar shape, recolored to Solana's official purple→green gradient on black.
Checked against 4.0.58 on 2026-10-11: every mark above is unchanged from 4.0.57 (byte-for-byte, Solana recolor aside).
Base (blue square), Optimism, Polygon/POL, BNB and USDT match the projects' current marks, so no brand-kit replacement was needed.
